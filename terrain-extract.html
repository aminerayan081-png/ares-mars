ARES terrain extractor (separate page)

Reads a small Gale Crater window (about 1 to 2 MB) from the MOLA 463 m elevation file and lets you save it as two small files for ARES. It changes nothing in ARES. Its decoding was checked here on a made-up file with the same layout; the real server run is yours.

Save both files, then upload them to your repo in the folder data/terrain.
